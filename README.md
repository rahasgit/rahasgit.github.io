# Personal GitHub Pages Website

## 1. Put these files in your GitHub repository

- `index.html`
- `style.css`
- `background.png`
- `profile.jpg` (your own portrait)

The generated `background.png` is already included.

## 2. Edit your details

In `index.html`, replace:

- `Your Name`
- `YOUR-USERNAME` in the LinkedIn, GitHub, and Hugging Face links
- the About Me text
- the Updates
- the Publications

Replace `profile.jpg` with your own photo.

## 3. Enable GitHub Pages

On GitHub:

**Repository → Settings → Pages → Build and deployment → Deploy from a branch**

Choose your main branch and the `/ (root)` folder, then save.

Your site will normally become available at:

`https://YOUR-USERNAME.github.io/REPOSITORY-NAME/`

If the repository itself is named `YOUR-USERNAME.github.io`, the URL is:

`https://YOUR-USERNAME.github.io/`
